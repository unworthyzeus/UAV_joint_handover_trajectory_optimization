# References

This directory stores proposal files and small provenance records.

## Proposals

`proposals/I2R_proposal_UAV.pdf` is the canonical local copy of the two page proposal, “Joint Handover and Trajectory Optimization in 5G Connected UAVs.”

The byte identical `I2R_proposal_UAV (1).pdf` at the repository root preserves
the original delivered filename and mirrors the sibling project layout. New
references should use the canonical copy under this directory.

## Pages

URL shortcuts point to official records or primary publication pages. Full research PDFs belong under `sources/` when local storage is useful and permitted.

Each new source must also be mapped in `docs/09_data_and_sources.md` or `sources/README.md`.
